# BridgePad Privacy Policy

Last updated: September 4, 2026

BridgePad does not require an account and does not collect, transmit, sell or
share personal data. The Android application has no analytics, advertising,
cloud synchronization or telemetry service.

## Data processed on the device

BridgePad processes controller input, Android device information, paired
computer names and Bluetooth/USB connection state locally to provide its core
functionality and diagnostics.

USB gamepad mappings and first-run onboarding status are stored locally in the
application's private storage. They can be removed by clearing BridgePad's app
data or uninstalling the application.

## Bluetooth and nearby-device permissions

Bluetooth permissions are used to advertise BridgePad as a Bluetooth HID
gamepad, list paired computers and manage the user-requested connection. USB
permission is used only when the user enables direct Background USB capture.

## Diagnostic reports

BridgePad creates a diagnostic report only when the user requests it. The user
chooses whether and where to copy or share that report. Reports exclude
Bluetooth addresses, but may contain the Android device model, Android version,
controller name, vendor/product identifiers and recent technical session
events. Users should review a report before publishing it.

## Network access

The current Android MVP does not send controller state or diagnostics over the
internet. Future network functionality must update this policy before release.

## Changes

Material changes to this policy will be documented in the project changelog.
